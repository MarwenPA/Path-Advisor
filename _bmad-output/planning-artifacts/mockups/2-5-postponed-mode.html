Tests de validation visuelle

  • Test parité visuelle (Scène D, LE test critique) : les 2 cards Léa et Sarah doivent avoir strictement la même structure, même typographie, même couleur, même hiérarchie. Seul le contenu textuel de la phrase défendable et de la stat diffère. Si on couvre la métadonnée "Léa postponed" vs "Sarah avec bulletins" en haut, on ne peut PAS distinguer les deux.
  • Test bandeau footer dismissable (Scène A) : bouton "Ajouter" en outline secondary (pas brand primary), bouton dismiss ✕ discret. Au clic ✕, masqué pour 7 jours (TTL via API). Ne suit pas le scroll (sticky à la fenêtre, pas au contenu).
  • Test mini-CTA contextuel (Scène B) : apparaît dans la PAGE sous le graphe, pas en overlay. Bouton secondary (pas primary). Disparaît dès bulletins_status === "completed". Pas dismissable (contextuel, pas harcèlement).
  • Test stat range Léa (Scène B) : "30-45 %" en fourchette même typo display-2 que la stat chiffre précise Sarah. Label qualitatif "Pari audacieux" identique, suffixe "estimation indicative" calme et factuel.
  • Test BulletinsAddSheet (Scène C) : 2 boutons "Scanner / importer" + "Saisir à la main" strict même hauteur (56 px), même typographie, même padding. Aucun n'est en primary brand — c'est un choix libre, pas une recommandation directive. Bouton "Annuler" tertiary discret centré.
  • Test mots interdits : aucun "incomplet", "manque", "X %", "tu rates", "termine", "débloque tes VRAIES stats" dans les 4 scènes. Validation runtime dev sur les copy.
  • Test "même reco list" : Léa voit les 3 mêmes métiers (Avocate, Journaliste, Médecin) avec les mêmes scores (82 / 78 / 74 %) que Sarah verrait. Le score vocationnel est basé sur passions/valeurs (Story 2.1), pas sur les bulletins.
  • Test capture WhatsApp / screenshot : Léa screenshote son graphe parcours et l'envoie à Sarah. Sarah ne doit PAS deviner que Léa est en mode postponed — le mini-CTA pourrait trahir, mais il sort du re-rendu d'export StoryExport (Story 6 le gère).
  • Test focus a11y : Tab sur bandeau : "Ajouter" → ✕. Tab sur mini-CTA : "J'ajoute mes notes". Tab sur sheet : "Scanner" → "Manuel" → "Annuler". Focus ring 2 px brand + offset.
  • Test reduced motion : aucune animation propre sur cet écran (transitions hover collapse à 0 ms).
  • Test conversion KPI : chaque clic "Ajouter" / "J'ajoute mes notes" émet un event analytics distinct (bulletins_banner_clicked, bulletins_minicta_clicked avec entry_point). Le funnel postponed → completed est mesurable au tracking. Cible MVP ≥ 35 % en 4 semaines.
  • Test "rien ne suit Léa partout" : si Léa dismiss le bandeau, il reste masqué 7 jours sur toutes les pages. Le mini-CTA n'est pas dismissable mais n'apparaît que contextuellement (graphes, stats), jamais sur fiches métier ou liste.
