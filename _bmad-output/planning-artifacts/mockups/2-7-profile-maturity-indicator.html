Tests de validation visuelle

  • Test "AUCUN pourcentage" : recherche dans la page entière des caractères % ou des mots pourcentage, complet à X, il te manque, termine, tu rates. Aucun match dans les 3 variants × 3 niveaux. Match uniquement dans l'anti-pattern de référence (Section 5).
  • Test "couleur uniforme par niveau" : les 3 niveaux (base/enriched/complete) doivent avoir strictement la même couleur de fond, border, texte. Une couleur progressive (rouge → orange → vert) trahit le pattern stigma. Seul le libellé et la description changent.
  • Test "showCallToAction par défaut" : le bouton "Voir comment compléter" est PRÉSENT en base et enriched, ABSENT en complete (rien à compléter). Cohérent avec Story 2.7 AC1 default showCallToAction: level !== 'complete'.
  • Test "dashboard-card disparaît à complete" : Section 2 colonne 3 montre return null — composant absent du DOM (anti-bruit AC5). Sarah au complet ne voit pas de rappel maturité sur son dashboard.
  • Test "inline-compact pill discret" : 1 dot (base) / 2 dots (enriched) / 3 dots (complete) comme indicateur visuel discret sans couleur progressive. Au tooltip hover, la description complète apparaît.
  • Test "toast level-up calme" : couleur success #2F6B4F (vert sobre), pas brand #C8312D. Pas de confetti, pas d'icône célébration emoji 🎉. Auto-dismiss 3 s, dismissible manual. Émis 1 seule fois par transition (déduplication serveur sur flag maturity_celebration_shown_for_{level}_at).
  • Test "level-down silence" : si Sarah supprime ses bulletins et redescend de enriched → base, AUCUN toast (pas de "tu as régressé"). La card maturité reflète silencieusement le nouveau niveau au prochain refresh.
  • Test sprint review copy : Léa proxy lit la description du niveau base. Si elle pense "donc je manque de trucs", on refait. Cible : "Voilà ce que j'ai aujourd'hui — je peux explorer, je verrai si je veux compléter."
  • Test runtime validation dev : si un dev passe une title ou description contenant les mots interdits (cf §4.3 Story 2.7), un console.warn est émis. Garde-fou minimal anti-drift.
  • Test focus a11y : Tab traverse les boutons "Voir comment compléter" / "Mon profil →" / pills. Focus ring 2 px brand + offset. Toast success dismissable au clavier (Esc OK aussi).
  • Test reduced motion : aucune animation propre sur les composants ; transitions hover collapse à 0 ms.
  • Test parité Léa vs Sarah : dans une UI réelle, Léa postponed verra "Profil de base" et Sarah enriched. Aucune autre différence visuelle ailleurs dans l'app ne signale leur état différent (cf Story 2.5). Le maturity indicator est le SEUL endroit où le niveau est expliqué — toutes les autres pages restent agnostiques.
