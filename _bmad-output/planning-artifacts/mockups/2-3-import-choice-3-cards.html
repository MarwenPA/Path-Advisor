  • Test parité Mehdi/Léa/Sarah : les 3 viewports mobiles ci-dessus sont strictement identiques. Si tu peux distinguer celui de Léa au premier coup d'œil, le mode dégradé invisible est cassé.
  • Test 3 secondes : couvre l'écran et révèle-le 3 s. Tu dois pouvoir nommer les 3 options sans les relire.
  • Test focus a11y : la 2e card du viewport desktop est en état focus-visible (focus ring brand 2 px + offset). Tab dans une vraie implémentation produira ce résultat.
  • Test touch target : chaque card mesure ≥ 80 px de haut (size xl AC1). Mesure à la règle dans le devtools = OK.
  • Test reduced motion : active prefers-reduced-motion: reduce dans devtools → l'animation de chevron au hover disparaît, le reste reste fonctionnel.
  • Test daltonisme : active le simulateur daltonisme devtools (deuteranopie / protanopie / tritanopie) — aucun signal critique n'est porté par la couleur seule.
